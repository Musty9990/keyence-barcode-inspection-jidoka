# Project contribution and documentation notes

This repository is a portfolio record of an educational automation demonstration.

Before adding files:
- Confirm you have permission to publish them.
- Remove passwords, credentials, customer data, plant network details and other confidential information.
- Label simulated behavior separately from tests on physical hardware.
- Record software/firmware versions and test evidence where available.
- Do not describe planned work as implemented.
- Do not use the partial tag table as a wiring reference.
